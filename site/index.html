Cài đặt

🐧 Linux (Ubuntu/GNOME)

sudo apt install build-essential pkg-config \
  libibus-1.0-dev libgtk-3-dev \
  libayatana-appindicator3-dev librsvg2-bin
./gtv.sh build
sudo ./gtv.sh install

Rồi thêm GoTV trong Settings → Keyboard → Input Sources, chuyển bằng Super+Space.

🪟 Windows 10/11

Chạy gotv-*-x64-setup.exe từ trang Releases → đăng xuất/đăng nhập lại → chọn GoTV bằng Win+Space.

Câu hỏi thường gặp

GoTV có phải GoTiengViet của Trần Kỳ Nam không?

Không. GoTV là dự án độc lập của isthaison, trước đây mang tên GoTiengViet. Từ phiên bản 0.9.0, dự án đổi tên để tránh nhầm lẫn với phần mềm của Trần Kỳ Nam.

Khác gì Unikey / EVKey?

GoTV dùng một lõi C chung cho cả 3 OS, có chính tả khi gõ (gạch đỏ trên Linux, balloon gợi ý trên Windows/macOS) và gợi ý từ điển offline — những thứ Unikey/EVKey không có. Unikey vẫn gọn nhẹ nếu bạn chỉ cần gõ cơ bản trên Windows.

Có cần mạng không?

Không. Gõ, chính tả, macro/emoji, gợi ý từ điển đều ngoại tuyến. Mạng chỉ dùng khi kiểm tra bản mới / cập nhật từ điển từ GitHub.

Gõ 1 ra ă trên Windows?

Đó là layout VIE của Windows đặt chữ Việt ở hàng số. GoTV đã ép dịch phím qua layout US nên gõ 1 ra 1 đúng. Nếu còn bị: kiểm tra đang dùng bàn phím GoTV (không phải Vietnamese Telex của Microsoft) và cập nhật bản mới nhất.

macOS báo “unidentified developer”?

Bản preview chưa ký số Apple. Chuột phải vào app → Open để chấp nhận một lần. Bản ổn định sẽ được ký + notarize.

Cả câu bị gạch đỏ trong trình duyệt?

Không phải GoTV (bộ gõ không vẽ gạch đỏ). Đó là spellchecker tiếng Anh của trình duyệt hoặc Windows gặp chữ Việt — tắt spellcheck ở ô nhập đó hoặc thêm tiếng Việt vào trình duyệt là hết.

Mất GoTV sau cập nhật Windows?

Đăng xuất/đăng nhập lại; nếu chưa thấy: Settings → Time & Language → Language → Options → Add a keyboard → GoTV.

Cấu hình lưu ở đâu?

Linux/macOS: ~/.config/gotv/ — Windows: %APPDATA%\gotv\. Macro/emoji/từ điển học đều là file text, sửa tay được. Chi tiết →
