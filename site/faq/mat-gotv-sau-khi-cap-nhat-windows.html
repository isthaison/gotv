Bị mất biểu tượng GoTV sau khi cập nhật Windows Update?

Cập nhật lần cuối: 07/11/2026 · Tác giả: GoTV Project (isthaison)

1. Nguyên nhân

Khi Windows cập nhật các phiên bản tích lũy hoặc bản nâng cấp tính năng lớn (ví dụ: Windows 11 23H2, 24H2...), hệ điều hành thường thiết lập lại một số nhánh đăng ký trong Registry của hệ thống phân phối ngôn ngữ (Text Services Framework - TSF). Điều này có thể làm ẩn tạm thời bàn phím của bên thứ ba khỏi thanh chọn ngôn ngữ Taskbar.

2. Các bước khôi phục đơn giản

Bước 1: Đăng xuất và đăng nhập lại Windows (Sign Out)

Đa phần các trường hợp, chỉ cần đăng xuất tài khoản Windows của bạn (bấm nút Start → nhấp vào avatar của bạn → chọn Sign out) rồi đăng nhập lại là TSF subsystem sẽ tự động nhận diện lại GoTV.

Bước 2: Thêm lại GoTV trong Cài đặt Windows

  1. Mở Settings (phím tắt Windows + I).
  2. Vào mục Time & Language → Language & Region.
  3. Chọn gói ngôn ngữ bạn đang dùng (ví dụ: English (United States) hoặc Tiếng Việt), bấm vào dấu 3 chấm ... → chọn Language options.
  4. Cuộn xuống phần Keyboards → bấm Add a keyboard.
  5. Tìm và nhấp chọn GoTV trong danh sách.

Bước 3: Chạy lại file cài đặt GoTV

Nếu hai cách trên vẫn chưa kích hoạt lại được, bạn chỉ cần tải lại hoặc mở file cài đặt gotv-*-x64-setup.exe đã tải trước đó và cài đặt đè. Bộ cài đặt sẽ tự động đăng ký lại các tệp DLL TSF 32-bit và 64-bit mà không làm mất cấu hình cá nhân hay từ điển tự học của bạn.
